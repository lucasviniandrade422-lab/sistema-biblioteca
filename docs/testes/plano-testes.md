# Plano de Testes

## Teste 1 - Empréstimo com sucesso
Cenário: Empréstimo de livro disponível  
Entrada: Usuário cadastrado solicita um livro disponível  
Resultado esperado: O sistema realiza o empréstimo com sucesso  

## Teste 2 - Livro indisponível
Cenário: Tentativa de empréstimo com livro indisponível  
Entrada: Usuário tenta pegar um livro já emprestado  
Resultado esperado: O sistema informa que o livro não está disponível  

## Teste 3 - Usuário não cadastrado
Cenário: Empréstimo com usuário não cadastrado  
Entrada: Usuário não registrado tenta realizar empréstimo  
Resultado esperado: O sistema informa que o usuário precisa estar cadastrado
