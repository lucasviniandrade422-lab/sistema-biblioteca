# Requisitos do Sistema - Sistema de Biblioteca

## Requisitos Funcionais

RF01 – O sistema deve permitir o cadastro de usuários.

RF02 – O sistema deve permitir o cadastro de livros.

RF03 – O sistema deve registrar empréstimos de livros.

RF04 – O sistema deve permitir a devolução de livros.

RF05 – O sistema deve permitir consultar livros disponíveis.

RF06 – O sistema deve permitir editar dados de usuários.

RF07 – O sistema deve permitir editar dados de livros.

RF08 – O sistema deve listar os empréstimos realizados.

---

## Requisitos Não Funcionais

RNF01 – O sistema deve armazenar senhas criptografadas.

RNF02 – O sistema deve possuir autenticação de usuários.

RNF03 – O sistema deve responder às requisições em até 3 segundos.

---

## User Stories

Como bibliotecário, eu quero cadastrar novos livros para organizar o acervo.

Como usuário, eu quero realizar login para acessar minhas funcionalidades.

Como bibliotecário, eu quero registrar empréstimos para controlar os livros emprestados.
